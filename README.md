# Port Scanner TCP

Scanner de portas TCP em Python, feito para o Roteiro 4 de Tecnologias Hacker (Insper).

A ideia é tentar abrir uma conexão TCP com cada porta e, pelo resultado da tentativa,
dizer se ela está aceitando conexões. Só biblioteca padrão do Python, sem Nmap por baixo.

> Use só em máquinas suas ou em que você tenha autorização para testar.
